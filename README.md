## 📌 Repository Overview

* **Automatic Sync:** Submissions and problem metadata are fetched automatically using Python and GitHub Actions.
* **Rating Organization:** Java solution files are placed in difficulty folders (e.g., `solutions/rating-0800-1000/`).
* **Sequential Order:** Problems are logged in chronological order starting from `#001`.
